# Обоснование разделения на домены

Были выделены домены:

- Портал пользователей
- Медицинская система DLH
- BI-Система
- Конструктор отчетов
- Бизнесс сервисы компании
- Медицинские сервисы компании
- Финансовые сервисы компании
- ИИ сервисы компании

Для каждого из этих доменов можно выделить по специализированной команде разработчиков с определенной компетенцией. 

При малом количестве сотрудников одна команда может работатьнад несколькими доменами со схожим тех-стеком.

Для DLH рекоммендуется выделить отдельную команду разработчиком


Преимущества:

- Сокращение Time-To-Market
- Повышение качества данных
- Повышение надежности системы
- Упрощение масштабирования системы
